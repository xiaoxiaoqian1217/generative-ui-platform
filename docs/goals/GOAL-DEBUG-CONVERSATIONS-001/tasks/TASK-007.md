# TASK-007：保留、删除与部分失败恢复

## 目标

实现调试历史的保留、资源治理、双侧删除和部分失败恢复。

## 交付

- 默认清理三十天前的非活动历史。
- 提供单线程删除和清空全部调试历史。
- 协调 Runtime Thread Repository 与 Business Agent Checkpoint Store 删除。
- 显式显示 completed、partial 和 failed 删除结果。
- 提供安全的人工重试和孤立记录诊断。
- 不自动重复执行 Run 或 Action。

## 验收

- 清理任务幂等，并且不会删除保留期内的活动线程。
- 任一存储不可用时不会谎报全量删除成功。
- 部分删除可以被后续重试收敛。
- 数据大小和数量限制在并发条件下仍然生效。

## 依赖

TASK-004、TASK-005 和 TASK-006。
