# Triage 标签

工程技能使用五种规范的 triage 角色。
本文件将这些角色映射到仓库 Issue 跟踪系统中的实际标签。

| 规范角色          | GitHub 标签         | 含义                         |
| ----------------- | ------------------- | ---------------------------- |
| `needs-triage`    | `needs-triage`      | 需要维护者评估 Issue         |
| `needs-info`      | `needs-info`        | 等待报告者补充信息           |
| `ready-for-agent` | `ready-for-agent`   | 定义完整，可以交给 agent     |
| `ready-for-human` | `ready-for-human`   | 需要人工实现                 |
| `wontfix`         | `wontfix`           | 不会处理                     |

当技能提到某个角色时，使用表中对应的 GitHub 标签。
如果仓库采用其他标签词汇，修改 GitHub 标签列。
