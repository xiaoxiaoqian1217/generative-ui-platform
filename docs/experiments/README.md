# 实验记录

`docs/experiments/` 用于保存按照 Research Protocol 执行的单次实验记录。

实验记录不是产品规范，也不是最终结论。每个实验必须能追溯到明确的 Research Question、Hypothesis、控制变量、证据和退出判据。

## 目录

- [`map/`](./map/)：地图场景 Agent–User Interaction 实验。

## 规则

1. 开发实验能力前先建立 Experiment Card。
2. 单次实验只改变一个核心变量。
3. 工程证据、行为证据、主观证据和质性证据分开记录。
4. 实验结论必须标注 Evidence Level（E0–E4）。
5. 阶段性稳定结论进入 `docs/reports/`，不直接把单次实验结果提升为产品原则。

上位研究协议见 [`docs/research/AGENT-USER-INTERACTION-MAP-RESEARCH-PROTOCOL.md`](../research/AGENT-USER-INTERACTION-MAP-RESEARCH-PROTOCOL.md)。
