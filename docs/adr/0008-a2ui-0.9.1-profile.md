# ADR-0008: 锁定 A2UI 0.9.1 Profile

- **状态：** 已接受
- **日期：** 2026-07-27

## 背景

A2UI 0.9.1 是 v0.9 协议系列的补丁版本。
其服务端到客户端消息使用 `version = "v0.9"`，而不是 `version = "v0.9.1"`。
Compiler 还需要定义从协议无关 UI IR 到扁平 A2UI 组件属性、绑定和 Action 的精确映射。

## 决策

MVP 使用 A2UI 0.9.1 版本作为校验和 Profile 基线。
每条输出消息都使用线路判别字段 `version = "v0.9"`。

MVP Profile 使用以下操作输出初始完整 Surface：

- `createSurface`；
- `updateComponents`；
- `updateDataModel`。

Profile 不输出 `deleteSurface` 或 Surface 替换操作。

Component Props 在编译为 A2UI 前先在 UI IR 中进行规范化和校验。
A2UI Compiler 使用现有名称将非保留 Props 扁平化。
Binding 在其目标属性下转换为标准 JSON Pointer 对象。
经过校验的 Action 转换为 Profile 定义的 `action.event` Envelope。
最终 A2UI Payload 将作为整体接受 0.9.1 Profile Schema 校验。

## 后果

- Profile 发布版本元数据和消息线路版本保持区分。
- A2UI 消息判别字段使用 `"v0.9.1"` 时会被拒绝。
- 每个受支持的组件类别都必须包含 Props、Binding 和 Action 映射测试。
- 未来升级 A2UI 版本或扩展 Surface 生命周期需要新的 ADR 和带版本的契约变更。
