# Generative UI Workbench 文档说明

原文档 `docs/WEB_WORKBENCH_SRS.md` 继续保留，作为 Workbench 子系统的需求输入和评审材料。

## 当前定位

Generative UI Workbench 是 Frontend Runtime 参考实现、平台开发联调工作台、A2UI Renderer 和 Component Registry 验证环境，以及平台诊断、验收和回归入口。

它可以发布到测试环境，但不是独立企业业务产品、正式智慧安防生产系统或最终用户商业产品。

## 原文档术语

原 SRS 中的“产品背景”“产品目的”“产品定位”等章节，是从软件交付物需求视角描述 Workbench。

这些表述不代表 Workbench 被提升为独立商业产品，也不改变它作为平台开发验证环境的主要定位。

平台级定位以以下文档为准：

- `docs/platform/REQUIREMENTS.md`
- `docs/platform/ARCHITECTURE.md`
- `docs/platform/DEVELOPMENT_ENVIRONMENT.md`
- `docs/goals/GOAL-DEV-ENV-001.md`
